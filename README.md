# EduPulse AI

A personalized AI study companion. Upload a PDF textbook or syllabus, then chat with it,
generate practice quizzes and study with flashcards.

> Work in progress — built step by step following a 30-day plan
> (Python + Streamlit → LLM APIs → RAG pipeline → full app + deployment).

## Getting started

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
cp .env.example .env          # then add your OpenAI API key
```
